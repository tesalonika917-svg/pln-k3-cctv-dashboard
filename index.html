Cara Menggunakan Dashboard

  1. Buka menu Dashboard untuk melihat ringkasan data.
  2. Buka Monitoring Harian untuk melihat data monitoring berdasarkan waktu.
  3. Buka Data Laporan untuk melihat seluruh data laporan CCTV.
  4. Gunakan kolom pencarian untuk mencari pekerjaan, CCTV, lokasi, UP3, ULP atau petugas.
  5. Gunakan tombol Export CSV untuk mengunduh data.
  6. Gunakan tombol ⚙ Sumber Data untuk memuat atau memperbarui data Spreadsheet.
